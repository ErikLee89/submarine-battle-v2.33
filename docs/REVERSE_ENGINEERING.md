# V2.33 机器码与浏览器兼容层

## 来源

输入文件为 `D:\test\ship_V2.33.exe`，802816 字节；ImageBase `0x400000`，PE 入口 `0x41101B`。这是静态链接 MFC 的独立构建，未沿用 V2.00 的函数地址、对象字段或资源对应。

`tools/export.py` 提取 PE 中的 68 个 RT_BITMAP 和 7 个 WAVE 资源。位图包含 RLE 压缩，由 Pillow 无损解码。它也导出原始区段，使用 Capstone 解码；对于跳转表后的入口，额外从直接控制流目标及数据中的函数指针重新解码。`docs/disassembly.txt` 是辅助查看的线性反汇编，运行时以 `machine.js` 中的入口解码为准。

## 直接执行的游戏入口

| 地址 | 用途 |
|---|---|
| `0x4024C8` | 主游戏对象构造 |
| `0x40368C` | OnCreate：资源、背景、数组、随机数初始化 |
| `0x4046C7` | 更新、碰撞、生成、计分、绘图主循环 |
| `0x409F8C` | 重新开始 |
| `0x40A1EB` | 暂停 / 继续 |
| `0x40A234` | 过关与第 21 关循环 |
| `0x40A5A9` / `0x40A9D6` | 按键按下 / 松开 |
| `0x40457F` / `0x40AA54` / `0x40BF76` | 左击、鼠标移动、右击 |
| `0x40AC5A` | 结束游戏 |
| `0x40AA8D` / `0x40AD85` | 原版排名插入 / 英雄榜内容准备 |
| `0x40CA30` / `0x40CD23` | 原版英雄榜文件读取 / 写入 |
| `0x40D177` / `0x40DC35` | 原版存档序列化 / 读取 |
| `0x40C18A` / `0x40C51D` | 原版天空 / 海水渐变绘制 |
| `0x410B1A` / `0x410B27` | 原版 srand / rand |
| `0x410C78` | 原版浮点转整数，执行其指令而非替代玩法 |

原版消息映射中的 `0x7001` 指向 `0x40AA8D`，处理结束后的英雄榜。命令 `0x8022`、`0x8023`、`0x8024` 分别执行核武器、机会、炸弹容量奖励函数。用户界面输入被转换成这些原版处理器的调用。

## 核心字段

主对象在浏览器 VM 中位于 `0x500000`。字段偏移保持原版。

| 偏移 | 含义 |
|---|---|
| `+0x1DC` | 从 0 开始的关卡序号 |
| `+0x21C` | 剩余机会，初始 5 |
| `+0x224` / `+0x228` | 舰艇 X / Y |
| `+0x1F0` / `+0x2F4` | 使用中的炸弹数 / 容量，初始容量 5 |
| `+0x3B0` | 持有核武器数 |
| `+0x3AC` / `+0x3B8` | 总得分 / 消灭数 |
| `+0x308` | 主循环间隔，默认 31 毫秒 |
| `+0x30C` | 鼠标控制开关 |
| `+0x210` | 第 11 关后的双战场模式 |

Windows 系统服务通过 IAT 映射进入浏览器实现；MFC 字符串、内存分配、图像列表、画笔、文本、虚拟文件服务在库边界替代。原版更新和绘图函数继续执行。对话框使用 HTML 控件；英雄榜名称进入原版 ANSI 字符串时按 GBK 编码及 12 字节上限处理。

## 验证范围

`verify_machine.py` 在浏览器中记录兼容服务的输入、输出及内存写入，再让 Unicorn 执行未修改的 x86 区段，重放相同服务结果并比较控制流、寄存器和内存。它不会独立验证 Windows/MFC 服务实现，也不是原程序的真实窗口截图对照。

`test_gameplay.py` 用定向设置覆盖全部 21 关；保护字段与核武器数量的修改只用于测试，正常游戏不注入这些条件。`test_ui.py` 检查浏览器交互和布局。JSON 结果保存在本目录。
