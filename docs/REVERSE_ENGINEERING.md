# V2.33 机器码与浏览器兼容层

## 来源

输入文件为 `D:\test\ship_V2.33.exe`，802816 字节；ImageBase `0x400000`，PE 入口 `0x41101B`。这是静态链接 MFC 的独立构建，未沿用 V2.00 的函数地址、对象字段或资源对应。

`tools/export.py` 提取 PE 中的 68 个 RT_BITMAP 和 7 个 WAVE 资源。位图包含 RLE 压缩，由 Pillow 无损解码。它也导出原始区段，使用 Capstone 解码；对于跳转表后的入口，额外从直接控制流目标及数据中的函数指针重新解码。`docs/disassembly.txt` 是辅助查看的线性反汇编，运行时以 `machine.js` 中的入口解码为准。

| 地址 | 用途 |

| `0x4024C8` | 主游戏对象构造 |
| `0x40368C` | OnCreate：资源、背景、数组、随机数初始化 |
| `0x4046C7` | 更新、碰撞、生成、计分、绘图主循环 |
| `0x409F8C` | 重新开始 |

| `0x40A5A9` / `0x40A9D6` | 按键按下 / 松开 |
| `0x40457F` / `0x40AA54` / `0x40BF76` | 左击、鼠标移动、右击 |
| `0x40AC5A` | 结束游戏 |
| `0x40AA8D` / `0x40AD85` | 原版排名插入 / 英雄榜内容准备 |

## 核心字段

主对象在浏览器 VM 中位于 `0x500000`。字段偏移保持原版。

| 偏移 | 含义 |
|---|---|
| `+0x1DC` | 从 0 开始的关卡序号 |
| `+0x21C` | 剩余机会，初始 5 |
| `+0x224` / `+0x228` | 舰艇 X / Y |
| `+0x1F0` / `+0x2F4` | 使用中的炸弹数 / 容量，初始容量 5 |
| `+0x3B0` | 持有核武器数 |
| `+0x3AC` / `+0x3B8` | 总得分 / 消灭数 |
| `+0x308` | 主循环间隔，默认 31 毫秒 |
| `+0x30C` | 鼠标控制开关 |
| `+0x210` | 第 11 关后的双战场模式 |

Windows 系统服务通过 IAT 映射进入浏览器实现；MFC 字符串、内存分配、图像列表、画笔、文本、虚拟文件服务在库边界替代。原版更新和绘图函数继续执行。对话框使用 HTML 控件；姓名输入在原版 `CDialog::DoModal` 服务边界暂停 VM，保留寄存器、栈和返回地址，用户确认或取消后从该位置继续执行原版排名和写入函数；英雄榜名称进入原版 ANSI 字符串时按 GBK 编码及 12 字节上限处理。

## 可关闭的玩法参数扩展

`tuning.js` 默认不安装任何玩法钩子。启用自定义后，深水炸弹使用独立的 100×56 字节对象池，原 `+0x1A8` 中的敌方弹药仍使用原来的槽位 10–34。仅在确认的友方炸弹指针读取位置重定向对象池，碰撞和得分继续执行原指令。原更新循环处理前 25 个槽位；`0x40852D` 至 `0x40859F` 的炸弹运动/绘制区段继续处理额外槽位。炸弹连击标志 `+0x234` 同步扩展为 100 项。横排投弹复制原版生成的炸弹对象，再排列 X 坐标；数量受空余额度限制。

`0x40997C` / `0x409996` 的位移读取应用自定义速度，保留原速度升级补给的加倍效果。原金钟罩设置位置 `0x407A55` 和复活保护位置 `0x409511` 将秒数转换成当前帧间隔下的保护计数 `+0x24C`；持续无敌通过 `+0x25C` / `+0x23C` 保持保护。重新开始后重设所选生命与弹药上限。关闭自定义时移除所有这些钩子，原始区段和指令映射本体不被改写。

原版存档的单个十六进制字段无法表示 100 枚弹药或 999 次生命。扩展格式 `ship233-custom` 包装原版 2109 字节数据，并保存完整参数、保护计数、炸弹对象与连击标志；原序列化时暂以字段宽度输出兼容的低位值，读取后从扩展字段恢复完整值。自定义扩展仅由网页读取，原版模式仍直接读写原 `.mine`。

## 验证范围

`verify_machine.py` 在浏览器中记录兼容服务的输入、输出及内存写入，再让 Unicorn 执行未修改的 x86 区段，重放相同服务结果并比较控制流、寄存器和内存。它不会独立验证 Windows/MFC 服务实现，也不是原程序的真实窗口截图对照。

`test_gameplay.py` 用定向设置覆盖全部 21 关；保护字段与核武器数量的修改只用于测试，正常游戏不注入这些条件。`test_ui.py` 检查浏览器交互和布局。`test_tuning.py` 覆盖自定义模式的 21 关、100 枚弹药与扩展槽位碰撞、生命/保护、存档和窄屏设置；机器码对照在关闭自定义的原版模式进行。JSON 结果保存在本目录。
